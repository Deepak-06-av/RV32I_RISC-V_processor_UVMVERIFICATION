# RV32I_RISC-V_processor_UVMVERIFICATION
32-bit single-cycle RISC-V (RV32I subset) processor in Verilog, verified using a SystemVerilog UVM 1.2 testbench on Synopsys VCS. Supports ADD, SUB, AND, OR, ADDI, LW, SW, and BEQ instructions with self-checking scoreboard verification. RTL design and UVM verification complete; RTL-to-GDSII physical design planned.
